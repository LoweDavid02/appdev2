# React Native Todo App with Convex

A real-time todo app built with React Native (Expo) and Convex as the backend.

## Setup

### 1. Install dependencies
```bash
npm install
```

### 2. Set up Convex
```bash
npx convex dev
```
This will:
- Prompt you to log in / create a Convex account
- Create a new Convex project
- Generate the `convex/_generated/` files
- Create a `.env.local` file with your `EXPO_PUBLIC_CONVEX_URL`

### 3. (Optional) Seed the database
In the Convex dashboard, run the `seeder:seed` mutation to populate 10 sample tasks.

### 4. Start the app
```bash
npx expo start
```
Scan the QR code with Expo Go.

## Project Structure

```
├── App.tsx                  # Root component with ConvexProvider
├── screens/
│   └── TodoScreen.tsx       # Main todo UI
├── convex/
│   ├── schema.ts            # Database schema
│   ├── todos.ts             # CRUD API functions
│   └── seeder.ts            # Seed data mutation
└── .env.local               # Convex URL (auto-generated by npx convex dev)
```

## Features
- ✅ Add, toggle, and delete todos
- 🔍 Real-time search/filter
- 📊 Progress bar showing completion
- ⚡ Live updates via Convex WebSocket
